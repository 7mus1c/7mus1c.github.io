# 工程化

## 一、前端工程化基础认知

1. 前端工程化的定义与核心价值
   - 解决的行业痛点（效率低、协作难、质量差等）
   - 工程化与模块化、组件化的关系
   - 现代前端工程化的核心目标（标准化、自动化、可复用、可扩展）

2. 前端工程化的发展历程
   - 传统前端开发模式的局限
   - 工程化演进关键节点（工具链兴起、框架整合、云原生适配）
   - 当下前端工程化的主流趋势（微前端、Serverless、低代码融合）
3. 工程化落地的核心原则
   - 适配业务场景，拒绝过度工程化
   - 兼顾开发效率与运行性能
   - 可维护性与可扩展性优先
   - 团队协作标准化导向

## 二、前端工程化核心体系模块

### （一）项目初始化与脚手架

1. 脚手架的核心作用与价值
   - 统一项目目录结构
   - 内置规范与最佳实践
   - 降低项目搭建成本
2. 主流脚手架工具实战
   - 基础脚手架：Create React App、Vue CLI、Vite（快速初始化）
   - 自定义脚手架开发：Yeoman 核心原理、Plop 小工具集成
   - 企业级脚手架：封装业务模板、配置预设、插件化扩展
3. 项目基础配置规范
   - 目录结构设计（src、public、config、utils 等分层）
   - 环境变量配置（开发 / 测试 / 生产环境区分）
   - 编辑器配置（.editorconfig、IDE 统一设置）

### （二）模块化与组件化开发

1. 模块化规范演进
   - 传统模块化方案（CommonJS、AMD、CMD）
   - ES Module 核心特性与实战（import/export、动态导入）
   - 模块化打包原理（依赖解析、作用域隔离）
2. 组件化设计与实践
   - 组件分层思想（UI 组件、业务组件、页面组件）
   - 组件通信方案（Props、EventBus、Vuex/Pinia、Redux）
   - 组件复用技巧（组合优于继承、自定义 Hooks、Mixin 慎用场景）
   - 组件设计规范（命名、Props 校验、样式隔离）
3. 模块化工具链
   - 模块打包工具：Webpack 核心配置（Entry、Output、Loader、Plugin）
   - 轻量打包工具：Vite 原理（ESBuild 预构建、按需编译）、Rollup 库打包
   - 模块解析与优化（Tree-Shaking、代码分割、懒加载）

### （三）代码规范与质量保障

1. 代码风格规范
   - ESLint 配置与自定义规则（语法检查、风格约束）
   - Prettier 格式化工具（自动统一代码格式）
   - 配置集成（ESLint + Prettier 冲突解决、IDE 自动修复）
2. 代码质量检测
   - 静态类型检查：TypeScript 核心配置（类型定义、类型推断、严格模式）
   - 代码复杂度分析：SonarQube 集成、ESLint 复杂度规则
   - 依赖包安全检测：npm audit、Snyk 工具（漏洞扫描、依赖更新）
3. 提交规范与 Hooks 工具
   - Git 提交规范：Conventional Commits（feat/fix/docs/style 等类型定义）
   - 提交校验工具：husky + lint-staged（提交前代码检查）
   - 自动生成变更日志：standard-version、conventional-changelog

### （四）构建与部署自动化

1. 构建流程优化
   - 构建脚本编写（npm scripts、Shell 脚本）
   - 多环境构建配置（开发环境热更新、测试环境压缩、生产环境 tree-shaking）
   - 构建性能优化（缓存策略、并行构建、增量构建）
2. 自动化测试体系
   - 测试分类与核心工具（单元测试：Jest/Vitest；组件测试：React Testing Library/Vue Test Utils；E2E 测试：Cypress/Playwright）
   - 测试策略（测试覆盖率目标、关键流程优先测试）
   - 测试自动化集成（CI 流程中自动执行测试、测试失败阻断部署）
3. 持续集成与持续部署（CI/CD）
   - CI 流程设计（代码提交触发构建、测试、质量检测）
   - CD 流程设计（自动部署到测试环境、灰度发布、生产环境部署）
   - 主流工具集成（GitHub Actions、GitLab CI、Jenkins、Docker 容器化部署）
   - 环境管理与配置中心（动态配置、配置加密）

### （五）性能优化与监控

1. 前端性能优化
   - 构建阶段优化（代码压缩、图片优化、资源合并、懒加载）
   - 运行时优化（首屏加载优化、长列表优化、内存泄漏排查）
   - 网络优化（HTTP/2 适配、CDN 加速、缓存策略、接口请求优化）
2. 监控与告警体系
   - 性能监控：Core Web Vitals 指标（LCP、FID、CLS）、Performance API
   - 错误监控：Sentry 集成（前端报错捕获、堆栈分析、用户行为回溯）
   - 业务监控：关键流程埋点、用户行为分析、告警配置

## 三、工程化技术选型与实战

1. 不同技术栈的工程化方案
   - React 技术栈：Create React App → 自定义 Webpack → Vite 迁移、Redux 生态、React Router 路由管理
   - Vue 技术栈：Vue CLI → Vite 迁移、Pinia 状态管理、Vue Router 配置
   - 跨端项目：Taro/Uniapp 工程化配置、小程序工程化适配
2. 企业级工程化实战案例
   - 大型项目目录结构设计（按业务模块拆分 vs 按功能分层）
   - 工程化配置封装（统一配置包、插件化管理）
   - 多团队协作工程化规范（分支管理策略、代码评审流程）

## 四、前沿工程化趋势与扩展

1. 微前端工程化
   - 微前端核心方案（qiankun、single-spa）
   - 微前端工程化关键点（应用隔离、共享依赖、路由分发、构建部署协同）
2. Serverless 与前端工程化
   - Serverless 部署流程（Vercel、Netlify、云厂商 Serverless 服务）
   - 前端一体化（BFF 层设计、Node.js 中间层集成）
3. 低代码与工程化结合
   - 低代码平台工程化能力（自定义组件接入、配置导出规范）
   - 低代码与传统开发协同方案
